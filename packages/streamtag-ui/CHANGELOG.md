# Changelog

## 0.1.0

Initial release.

- Define trusted React components with Zod 4 schemas and generate model instructions from the same catalog.
- Stream XML-style HTML and component props, including nested arrays with `<item>` entries.
- Grow text progressively and publish numeric values only after their closing tag.
- Update mounted React components as valid data arrives; isolate invalid props and render failures.
- Provide a React-free server entry point, ESM exports, and TypeScript declarations.
